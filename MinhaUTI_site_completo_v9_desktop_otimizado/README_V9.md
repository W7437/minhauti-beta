# MinhaUTI v9 — desktop otimizado

Principais mudanças:
- layout desktop ocupa praticamente toda a largura disponível;
- leitos e ferramentas ficam em colunas laterais compactas;
- abas do Minha UTI não usam rolagem horizontal no desktop;
- dispositivos em 3 colunas: CVC/PAI, SVD/CDL, TOT-IOT/TQT;
- campos e cards reorganizados para reduzir rolagem vertical;
- módulos complementares usam a largura inteira da área central;
- módulos complementares não escrevem automaticamente no Minha UTI.

A integração permanece de leitura: os módulos podem consultar contexto do leito ativo quando implementado, mas não alteram a evolução sem ação explícita do usuário.
