# DadosUTI — Guia de Prescrição de NPT v11

Esta versão copia o padrão de cards do módulo Gasometria:

- cabeçalho DadosUTI idêntico;
- círculos azuis numerados (`1`, `2`, `3`, `4`, `5`);
- títulos de seção no mesmo tamanho da Gasometria;
- botão "Limpar" no cabeçalho do primeiro card;
- botão principal azul ocupando toda a largura;
- cards brancos, bordas, raios e sombras no mesmo padrão.

## Estrutura
- `index.html`
- `style.css`
- `app.js`
- `.nojekyll`

O HTML usa `style.css?v=11` e `app.js?v=11`.
