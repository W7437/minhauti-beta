# MinhaUTI — TFG e ajuste Antibiótico

Equações:
- Cockcroft–Gault (CrCl; 1976)
- CKD-EPI 2021 creatinina
- CKD-EPI 2021 creatinina + cistatina C

Para CKD-EPI, quando peso e altura são fornecidos, a eGFR é desindexada pela superfície corporal
(Du Bois) para obter mL/min para decisão medicamentosa.

Antimicrobianos iniciais: ampicilina/sulbactam, piperacilina/tazobactam, cefazolina, cefepime,
ceftazidima, ceftriaxona, meropenem, ciprofloxacino, levofloxacino, metronidazol, azitromicina,
clindamicina e linezolida.

Referência posológica: UCSF Infectious Diseases Management Program.
