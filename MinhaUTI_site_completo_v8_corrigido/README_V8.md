# MinhaUTI v8 — correções de interface

Correções aplicadas:

1. Existe apenas uma barra global de Ferramentas. Os módulos em subpastas são conteúdo puro e não carregam navegação própria.
2. No desktop, Leitos, Conteúdo e Ferramentas são três colunas reais do mesmo grid; Leitos e Ferramentas iniciam alinhados pelo topo.
3. O banner Leito ativo permanece visível em todos os módulos e ocupa uma linha própria acima do conteúdo, sem sobreposição.
4. O iframe dos módulos usa redimensionamento automático no mesmo domínio para evitar barra de rolagem interna desnecessária.
5. Se um módulo for aberto diretamente por URL, aparece um pequeno link “Voltar ao MinhaUTI”; esse link é escondido quando o módulo está dentro do painel.

Slogan: **Menos tempo operacional. Mais tempo assistencial.**
